# What the dish?!

En quiz-app där användare får se en landsflagga och ska välja rätt nationalrätt eller känd maträtt från landet.

## Teknik
- React
- SQL
- Node.js/Express

## Funktioner
- Quiz med flaggor
- 4 svarsalternativ
- Ledtråd vid fel svar
- Bild på maträtten
- Kort historia om maträtten
- Bloggsida med alla länder och rätter
